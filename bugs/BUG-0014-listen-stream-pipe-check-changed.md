# BUG-0014 listen-stream の入力待ち判定を変えたが、パイプ入力の挙動は未検証

- 状態: 要検証
- 対象: x64 版（feature/x64-only）
- 起票: 2026-11-09

## 症状（コード上）
x64 版では FILE 内部の `_cnt`（バッファに残っているバイト数）を参照できないため、listen-stream の判定を変えた。ディスクファイル（GetFileType が FILE_TYPE_DISK）は待たずに getc で EOF を確かめる。それ以外（パイプ等）は従来どおりハンドルを待つ。

## 実測
差分と読み取りの確認のみ。パイプ入力で、バッファに既にデータがある場合の戻り値は未検証。テストは無い。
