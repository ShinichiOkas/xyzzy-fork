# BUG-0035 `(ash 0 <long を超える数>)` が 0 を返さず bignum-overflow を出す

- 状態: 修正済み（2026-11-22、8a01f16）
- 対象: x64 版（feature/x64-only）
- 起票: 2026-11-22（S3 の作業中に見つけた）

## 症状
- `(ash 0 n)` は n にかかわらず 0 であるべきだが、n が大きいとエラーになる。

## 実測（2026-11-22）
- `(ash 0 4294967296)` => 算術オーバーフローのエラー（`ash: (0 4294967296)`）
- `(ash 0 100000000000)` => 同上
