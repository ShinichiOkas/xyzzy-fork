# BUG-0015 pane.cc の戻り値が 64bit のアドレスを 32bit に切り詰める

- 状態: 要検証
- 対象: x64 版（feature/x64-only）
- 起票: 2026-11-09

## 症状（コード上）
src/pane.cc:538 は、テーブルのアドレスを `make_fixnum (long (uintptr_t (procs)))` で返す。x64 のアドレスは 32bit に収まらないため、上位ビットが失われる。

## 実測
コードの確認のみ。呼び出し元と、返された値の利用先は未確認。
