# BUG-0021 クラッシュレポートの書式 %08x に 64bit のポインタを渡している（表示のみ）

- 状態: 修正済み
- 対象: x64 版（feature/x64-only）
- 起票: 2026-11-09（ポインタ幅の監査による）

## 症状（コード上）
- src/except.cc:436、450-451、463 の `fprintf` / `sprintf` で、`%08x` に `PVOID` / `void *` を渡している。
- `app.initial_stack`（src/ed.h:432 の `void *`）には、src/init.cc:63 で `&tem` を代入している。

## 実測（2026-11-09）
- x64 ビルドの警告: `src/except.cc(436)`、`(450)`、`(463)` のそれぞれに C4477 と C4313（書式と引数の型が合わない）。
- 下位 32bit だけが出力される（書式の型と引数の型が合わないため）。

## 未確認
