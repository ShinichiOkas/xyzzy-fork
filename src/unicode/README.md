# src/unicode: mapping tables

These are the mapping tables from which the conversion tables of the codec
layer (`src/codec*.cc`, generated by `src/gen-codec.cc` into `src/gen/codec-tab.cc`)
and the old tables (`src/gen-ucs2tab.cc`) are built. The build reads only
these files; it does not use the code pages of the OS.

| file | what | origin |
|---|---|---|
| CP932.TXT | cp932 (Windows-31J) to Unicode, table version 2.01 (04/15/98) | https://www.unicode.org/Public/MAPPINGS/VENDORS/MICSFT/WINDOWS/CP932.TXT (taken on 2026-11-22). The file has no condition of use in it. Unicode.org publishes the files of the MAPPINGS directory under the Unicode Terms of Use, https://www.unicode.org/copyright.html |
| ibmext-sjis-eucjp.txt | the 388 IBM extension characters of Shift_JIS (FA40-FC4B) and their EUC-JP codes (OSF Japan Vendor Council table) | http://www.opengroup.or.jp/jvc/cde/ibmext-table.html. The pairs were carried in `gen-ibmext.cc` before; this file only moves them to a table |
| 8859-*.TXT, CP125x.TXT, KOI8-*.TXT | ISO 8859, Windows code pages, KOI8 | Unicode.org MAPPINGS (ISO8859, MICSFT/WINDOWS, VENDORS/MISC) |
| BIG5.TXT, GB2312.TXT, KSC5601.TXT, JIS0212.TXT, CNS11643.TXT | Big5, GB 2312, KS C 5601, JIS X 0212, CNS 11643 | Unicode.org MAPPINGS (EASTASIA) |
| eucJP-ibmext.txt | IBM extension characters in the rows 83 and 84 of JIS X 0212 | http://www.opengroup.or.jp/jvc/cde/eucJP-ibmext.txt |

Each file keeps the header that it came with. The Unicode.org files say that
the data are provided as is, with no claim of fitness for any purpose.

## What gen-codec.cc adds to CP932.TXT

CP932.TXT is a table for reading (code to Unicode). It does not tell which
code to write for a character that has more than one code, and it does not
have these:

- The user defined area F040-F9FC is U+E000-U+E757.
- The single byte 0x80 is U+0080. 0xA0 and 0xFD-0xFF are undefined (a byte
  that no character corresponds to).
- Writing: a Unicode that has more than one code takes the code of the
  first of these classes: JIS X 0208, NEC row 13 (87xx), IBM extension
  (FA-FC), NEC selected IBM extension (ED, EE). This is the code that
  `WideCharToMultiByte(932)` of Windows takes. `unittest/codec-tests.l`
  checks all the codes against the OS of the machine that runs the test.
